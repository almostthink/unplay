# 🏰 Мерж-Империя

Merge-игра для **Яндекс.Игр**: сливай одинаковые предметы, поднимай уровень,
выполняй заказы и строй империю. Полностью рабочий билд с прогрессом, облачными
сохранениями, рекламой, покупками, таблицей лидеров и локализацией.

**Размер архива: ~28 КБ.** Первый кадр появляется почти мгновенно, что важно
для ранжирования в каталоге Яндекса.

---

## Что внутри

### Геймплей
- Поле 6 колонок, от 4 до 7 рядов (ряды открываются за монеты).
- 4 цепочки по 9 уровней: **Шахта**, **Грядка**, **Мастерская**, **Алтарь**.
- Генераторы с зарядами: заряды копятся по таймеру, в том числе пока игра закрыта.
- Слияние двух одинаковых предметов даёт предмет следующего уровня, монеты и опыт.
- Долгое нажатие на предмет: карточка предмета и продажа.

### Прогресс
- Уровни империи с наградами и разблокировкой генераторов.
- 8 уровней апгрейда для каждого генератора (ёмкость, скорость, качество предметов).
- Заказы: 3 слота, награда в монетах, опыте и кристаллах.
- Ежедневные задания (3 из 5 шаблонов, цели масштабируются от уровня).
- Ежедневный сундук с серией на 7 дней.
- Оффлайн-доход до 4 часов.

### Монетизация
- **Rewarded video**: бесплатные кристаллы и монеты (с дневным лимитом),
  полная перезарядка генераторов, смена заказа, х2 к оффлайн-награде,
  х2 к ежедневному сундуку.
- **Interstitial**: только на естественных паузах, каждые 6 заказов или
  3 уровня, с собственным кулдауном поверх кулдауна SDK.
- **Sticky-баннер** с переключателем в настройках.
- **Внутриигровые покупки**: наборы кристаллов, набор новичка, отключение рекламы.

### Платформа
- Облачные сохранения `player.setData` + `localStorage`, побеждает более свежее.
- `player.setStats` для статистики в профиле игрока.
- Таблица лидеров по силе империи.
- Локализация: русский, английский, турецкий (берётся из `environment.i18n.lang`).
- Запрос оценки игры и ярлыка на рабочий стол, когда SDK это разрешает.
- Пауза звука на время показа рекламы и при сворачивании вкладки.

### Технически
- TypeScript в строгом режиме, Vite, нулевые рантайм-зависимости.
- Доска рисуется на Canvas, интерфейс на DOM: чёткий текст и простая локализация.
- Звук и музыка синтезируются через WebAudio, аудиофайлов в сборке нет.
- Графика предметов собирается из эмодзи и градиентов, картинок в сборке нет.
- Игра полностью работает вне Яндекса: SDK деградирует в заглушки.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # проверить продакшен-сборку
npm run zip        # build/game.zip для загрузки в консоль Яндекса
```

Вне фрейма Яндекса SDK не загрузится, это нормально: реклама сразу выдаёт
награду, покупки скрыты, таблица лидеров показывает заглушку.

## Публикация в Яндекс.Играх

1. **Создайте черновик игры** в [консоли разработчика](https://yandex.ru/dev/games/).

2. **Заведите таблицу лидеров.**
   Техническое имя должно совпадать с `LEADERBOARD_NAME` в
   `src/game/config.ts` (сейчас `empire`).
   Тип сортировки: по убыванию, формат: число.

3. **Заведите товары** с этими ID (или поменяйте их в `PRODUCTS`
   в `src/game/config.ts`):

   | ID | Тип | Что выдаёт |
   |---|---|---|
   | `gems_small` | расходуемый | 60 кристаллов |
   | `gems_medium` | расходуемый | 350 кристаллов |
   | `gems_large` | расходуемый | 1200 кристаллов |
   | `starter_pack` | расходуемый | 150 кристаллов, 2500 монет, полная перезарядка |
   | `no_ads` | нерасходуемый | отключает баннер и межстраничную рекламу |

   Количество кристаллов настраивается в `PRODUCT_GEMS`.
   Если товары не заведены, раздел покупок в лавке просто не показывается.

4. **Соберите архив:**

   ```bash
   npm run zip
   ```

   Загрузите `build/game.zip`. В корне архива лежит `index.html`, как требует
   платформа.

5. **Проверьте перед модерацией:**
   - Игра вызывает `LoadingAPI.ready()` сразу после загрузки (уже сделано).
   - Реклама не показывается в первые секунды и не прерывает действие игрока.
   - Звук глушится на время рекламы (уже сделано).
   - Игра работает и в портретной, и в альбомной ориентации.

## Настройка баланса

Вся экономика собрана в двух файлах, менять код не нужно:

- `src/game/config.ts` — кривая уровней, стоимость апгрейдов и рядов,
  награды за рекламу, частота межстраничной рекламы, ежедневные награды,
  шаблоны заданий, окно оффлайн-дохода.
- `src/game/items.ts` — цепочки предметов, названия на трёх языках,
  цвета плиток, стоимость предметов.

Например, сделать прогресс быстрее:

```ts
// src/game/config.ts
export function xpToNext(level: number): number {
  return Math.round(30 * Math.pow(level, 1.55)); // было 40 и 1.7
}
```

Добавить цепочку: допишите объект в массив `CHAINS` (9 уровней, эмодзи и
названия на ru/en/tr) и укажите `unlockLevel`. Генератор, апгрейды, заказы и
задания подхватят её автоматически.

## Структура

```
src/
├── main.ts              вход, игровой цикл, обучение, связывание модулей
├── sdk/yandex.ts        обёртка Yandex Games SDK, всё защищено от падений
├── core/
│   ├── storage.ts       облако + localStorage, троттлинг записи
│   ├── audio.ts         процедурный звук и музыка на WebAudio
│   ├── fx.ts            всплывающие числа, частицы, тосты
│   └── util.ts          форматирование чисел и времени, мелкие хелперы
├── game/
│   ├── config.ts        весь баланс
│   ├── items.ts         цепочки предметов и контент
│   ├── state.ts         состояние, миграция сейва, шина событий
│   ├── board.ts         генераторы, слияния, расширение поля
│   ├── orders.ts        генерация и выдача заказов
│   ├── quests.ts        ежедневные задания
│   ├── daily.ts         ежедневный сундук и серия
│   ├── offline.ts       расчёт оффлайн-прогресса
│   ├── economy.ts       монеты, кристаллы, опыт, уровни
│   └── ads.ts           политика показа рекламы и дневные лимиты
├── render/boardview.ts  canvas-доска, drag&drop, анимации
├── ui/                  HUD, заказы, док, модальные окна
└── i18n/index.ts        ru / en / tr
```
